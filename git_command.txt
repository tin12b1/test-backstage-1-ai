* Admin merge các nhánh chức năng vào dev

Admin vào GitHub:

Pull requests

Kiểm tra từng PR:

request-create → dev
approval-processing → dev
dashboard-config → dev
integration → dev

Với từng PR:
1. Xem tab Files changed
2. Kiểm tra conflict
3. Review code
4. Bấm Merge pull request
5. Confirm merge
Sau đó nhánh dev sẽ có code tổng hợp.

* Admin merge dev vào main

Khi code trên dev đã ổn định, Admin tạo PR:

base: main
compare: dev

Tiêu đề:

Merge dev into main for release

Mô tả:

Nội dung:
- Tổng hợp chức năng tạo yêu cầu
- Tổng hợp chức năng xử lý phê duyệt
- Tổng hợp dashboard/cấu hình
- Tổng hợp phần tích hợp

Kiểm tra xong thì Admin bấm:
Merge pull request
Confirm merge
* Quy trình hằng ngày cho cả nhóm

1. Checkout đúng nhánh của mình
2. Pull code mới nhất
3. Code
4. Commit
5. Push lên nhánh của mình
6. Tạo Pull Request vào dev

Merge code từ dev sang từng nhánh thành viên

Bạn làm trên máy của Admin.

Bước 1: Cập nhật nhánh dev mới nhất
git checkout dev
git pull origin dev

Nếu có code mới chưa đẩy lên GitHub thì đẩy trước:

git status
git add .
git commit -m "Update base code on dev"
git push origin dev

Nếu git status báo sạch thì không cần add/commit.

Bước 2: Đưa code từ dev sang nhánh request-create
git checkout request-create
git pull origin request-create
git merge dev
git push origin request-create

Ý nghĩa:

checkout request-create  : chuyển sang nhánh của thành viên
pull origin request-create : lấy code mới nhất của nhánh đó
merge dev                : đưa code từ dev sang nhánh này
push origin request-create : đẩy kết quả lên GitHub
Bước 3: Đưa code từ dev sang nhánh approval-processing
git checkout approval-processing
git pull origin approval-processing
git merge dev
git push origin approval-processing
Bước 4: Đưa code từ dev sang nhánh dashboard-config
git checkout dashboard-config
git pull origin dashboard-config
git merge dev
git push origin dashboard-config
