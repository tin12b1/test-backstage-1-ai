Cách chạy
Có hai cách:

Chạy từ file jar đã đóng gói (đang chạy sẵn cho bạn):
java -jar target\csdl-access-0.1.0.jar
Chạy trực tiếp bằng Maven (khi đang phát triển):
mvn spring-boot:run
Sau khi thấy dòng Started CsdlAccessApplication, mở trình duyệt vào:

Ứng dụng: http://localhost:8080/login
H2 console (xem dữ liệu DB): http://localhost:8080/h2-console — JDBC URL jdbc:h2:mem:csdl, user sa, password để trống.

Luồng test nhanh (mẫu 01-YCTC)
Đăng nhập requester1 / password (nhập thêm mã xác nhận hiển thị trong ảnh).
Dashboard → "Lập yêu cầu" → chọn 01-YCTC.
Nhập Ca, Hệ thống (chọn "He thong Core Kinh doanh"), CSDL, lý do, và ít nhất 1 dòng chi tiết → "Lưu nhập".
Ở khung "Ký xác nhận", nhập OTP 123456 → "Ký xác nhận" → "Gửi phê duyệt".
Đăng xuất, đăng nhập manager1 (chọn vai trò Trưởng phòng) → "Công việc" → mở phiếu → nhập OTP 123456 → "Ký xác nhận & chuyển tiếp".
Đăng nhập authority1 → phê duyệt tương tự → phiếu chuyển sang bộ phận Mở truy cập.
Đăng nhập access1 → "Công việc" → nhập OTP + thời gian thực hiện → "Xác nhận thực hiện" → phiếu Hoàn thành.
Có thể thử "Chuyển trả" (bắt buộc nhập lý do, không cần OTP) và tra cứu/xuất Excel ở menu "Tra cứu".
